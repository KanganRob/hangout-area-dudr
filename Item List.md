# Item List

This is a detailed **item list** containing information on **item names**, **rarity**, **stats** and its **passive effects**.

Before I start listing all the items, there's a few rules you should be made aware of regarding the different item rarities and any stat bonuses they apply.


## General Information
- Stat bonuses provided by items are **additive**, unless the source is from an **item's passive effect**.
- Item **passive effects** are __additive__ on to your character's **base** stat; e.g: if an item would grant you a **6x5%** ATK Boost and you have **80 Base ATK**, you gain **30%** of your **base ATK** as extra attack -- so **80 + 24 = 104 ATK**, not **80 * (1.05^6) = 107 ATK**.
- If a bonus provided by an item would result in the new value becoming a **decimal** number, it is **rounded up to the nearest whole number**; e.g, for the same example above, if you were instead gaining a **2%** ATK Boost with **80 Base ATK**, you would have **80 + 1.6 = 82 ATK**.
- Items have **different numbers of passives** based on their **rarity**, as demonstrated in the table below.

| Rarity | Stars | Stats | Item Passives |
|-|-|-|-|
| Common | ⭐ | 1 | 0 |
| Uncommon | ⭐⭐ | 1 | 1 |
| Rare | ⭐⭐⭐ | 2 | 1 |
| Epic | ⭐⭐⭐⭐ | 3 | 2 |
| Legendary | ⭐⭐⭐⭐⭐ | 5 | 3 |
| | | | |

*Note that in the **Item List** below, these will be notated by the number of **Stars** they have, **not** the name of the rarity.*

Characters are allowed to wield **1 type** of each item -- a **weapon**, **helmet**, **chestplate**, **gloves**, **pants** and **boots**, as well as **2 accessories**. Mixing and matching sets is perfectly fine; you don't have to stick to just one particular class.

Initially, characters will be given their class-specific **Uncommon** ⭐⭐ weapon, which can later be exchanged for better items as you progress through the campaign.

If you want to know more about a particular stat, head to the **Guide** page.
